# Full Body Training – Suivi mobile

Mini web-app mobile pour le suivi des cours Full Body Training de Rééduc & Vous.

Fonctions principales :
- deux groupes (19 h–20 h et 20 h–21 h) ;
- 7 séances + rattrapage ;
- présences rapides par date ;
- confirmation des inscriptions ;
- paiements cycle / séance à l’unité ;
- résumé par date et financier ;
- ajout / modification / suppression de participantes ;
- export CSV, sauvegarde et restauration JSON ;
- installation sur iPhone depuis Safari ;
- fonctionnement hors ligne via service worker.

## Confidentialité
Aucune donnée personnelle de participante n’est stockée dans ce dépôt public. Les données saisies dans l’app restent dans le stockage local du navigateur de l’appareil. Pour changer d’appareil, utiliser la sauvegarde JSON.
